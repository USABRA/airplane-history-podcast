# The Evolution of the Airplane

Animated educational video podcast presentation by Caio Ligabo for HIST 175.

Open the published GitHub Pages site, choose Iniciar apresentação, and use arrow keys to navigate. F toggles fullscreen, R hides controls for recording, and P pauses animation. No narration is included.

Historical and image credits appear in the presentation and its Sources menu. Third-party image rights and licenses remain with their respective owners. CC BY-SA image adaptations retain their license.
